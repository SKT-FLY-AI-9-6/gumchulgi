## 2. 검출기 계보 (누가 누구를 대체했나)

```
bt1702_detector.py (v0.1, 2채널, 결함 2개)
  └→ pse_analyze.py (구 팀 표준 4채널: LUM/RED/RG/BY)
       └→ pse_bt1702.py flat 시절 (jinsuk / final_detectors 사본)
            └→ psepipe_v3_seam  ← ★ 현행 (규격 특화 리팩토링: psecore/psefield/
                 │                  psepipe/tier/seam/margin + validation)
                 ├→ psegpu_full.py  (v3의 전 GPU 이식판 — 아래 3절 주의)
                 └→ pse_migraine.py (편두통 축 M1·M2, 08-14 추가, WARN 전용)
```

v3에서 **의도적으로 빠진 것**: RG/BY 색 대립축 (BT.1702 규격 외 채널이라 규격
준수 판정에서 제외 — pse_pattern.py 주석 참조). 규격 외 연구가 필요하면
`legacy_detectors/pse_analyze.py` 를 참조.

## 4. 보정(완화) 방식 정리 — 검출기와 별개로 세 갈래

| 방식 | 위치 | 성격 | 상태 |
|---|---|---|---|
| **게인 클램핑 (규격 기반)** | `psepipe_v3_seam/psepipe.py` (+seam) | 검출된 위반 구간의 휘도 전환을 규격 안으로 눌러줌. 실시간 지향, 결정론적 | 현행. STE 리포트 일관성 수정 진행 중 (fix 브랜치명 유래) |
| **All-in-One-Deflicker** | `Kim&Moon` 브랜치 | atlas 기반 blind deflicker (CVPR'23). 영상당 학습이라 느림, 오프라인 고품질용 | 가중치 포함 동작본 |
| **BlazeBVD 자체 학습** | `blazebvd` 브랜치 | STE prior + GFRM/LFRM (ECCV'24 재구현). atlas 대비 10배 빠름 | DAVIS 학습 체크포인트 보유. 잔상(다현 담당) 개선 대상 |

권장 역할 분담: 실시간/서비스 경로는 ① 게인 클램핑(+게인 시간축 스무딩·guided filter로
잔상 억제), 오프라인 고품질 경로는 ③ BlazeBVD, ②는 품질 비교 기준선.

## 5. 앞으로의 규칙 (제안)

1. **검출 로직 수정은 `psepipe_v3_seam/` 에서만.** 다른 브랜치의 검출기 사본에
   패치를 얹지 말 것 — 이번 조사에서 세 사본이 서로 다른 수정을 들고 있었다.
2. 개인 브랜치는 "개인 검출기 사본" 용도를 끝내고, 응용층(jinsuk 익스텐션 등)·
   보정기(Kim&Moon, blazebvd)처럼 **역할 단위**로 유지.
3. GPU 경로를 살리려면 (08-14 갱신): ~~pseenv·pselive3·verify_full 푸시~~ 완료.
   남은 순서 — ① `rawmeasure.py` 푸시 ② 합성 클립 생성(`legacy_detectors/make_testclips.py`,
   synth/·genre/ 폴더) ③ GPU 장비에서 `python verify_full.py` → **악화 0이 절대 조건**
   ④ 통과하면 psegpu_full을 현행 실행판으로 승격.
4. 이 브랜치(claude/direction-feedback-review-txg5t7)를 fix 브랜치 또는 main으로
   머지하면 통합이 완성된다.
