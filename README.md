|---|---|
| `seunghoon` | 화소별 WCAG 3조건 · BT.1702 · 모션 보정 하이브리드 |

```bash
git checkout main

```

## 공통 규칙

**영상 파일은 커밋하지 않는다.** 용량이 크고(편당 수십 MB), 수집 기록만
있으면 다시 받을 수 있다. 루트의 `.gitignore` 가 `*.mp4` 와 데이터 폴더를
막아 둔다 — 브랜치를 만들면 그대로 딸려온다.

**수집한 영상의 계정명·URL 도 커밋하지 않는다.** 제3자 개인정보다.

분석 결과(CSV·JSON)는 커밋한다. 수십 KB 이고 숫자의 근거다.
