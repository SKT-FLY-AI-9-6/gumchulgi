# legacy_detectors — 구세대 검출기 보관소 (수정 금지)

여기 파일들은 **현행 검출기가 아니다.** 현행 검출기는 `psepipe_v3_seam/` 하나뿐이다
(근거·계보는 `docs/검출기-통합.md`). 이 폴더는 비교·회귀·검증 목적으로만 보관한다.

| 파일 | 상태 | 남겨둔 이유 |
|---|---|---|
| `bt1702_detector.py` | v0.1 원조 (휘도+적색 2채널, 알려진 결함 2개) | 회귀 비교 기준선 |
| `pse_analyze.py` | 구 팀 표준 4채널 (LUM/RED/**RG/BY** 대립축) | RG·BY 대립축은 BT.1702 규격 외 채널이라 v3에서 의도적으로 제외됐다. 편두통 색상 축 연구 시 참고 가치 |
| `make_testclips.py` `make_cutclips.py` `make_seqclips.py` | 합성 검증 클립 생성기 | 정답을 아는 클립으로 검출기 회귀 검증. v3 검증에도 그대로 쓸 수 있다 |
| `README.txt` | 2026-08-10 스냅샷 당시 문서 | 당시 동작 확인 기록 포함 |

익스텐션·워처·리포트 등 응용층이다).
