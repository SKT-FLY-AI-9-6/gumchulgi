PSE 검출·보정 파이프라인 — 사용법
========================================================================

0) 준비
------------------------------------------------------------------------
  이 zip 을 한 폴더에 전부 풀어 주세요. 파일이 서로를 import 하므로
  **같은 폴더**에 있어야 합니다. 분석할 영상도 같은 폴더에 두면 편합니다.

  터미널(Windows: PowerShell 또는 cmd)을 그 폴더에서 엽니다.
    · 탐색기에서 폴더 열고 주소창에 cmd 입력 후 엔터
    · 또는  cd C:\경로\폴더

  필요한 패키지:
      pip install opencv-python numpy scipy pillow
  ffmpeg 도 필요합니다 (PATH 에 있어야 함).  ffmpeg -version 으로 확인.

  설치 확인:
      python -c "import cv2, numpy, scipy, PIL; print('ok')"


1) 판정만 보기 — 이 영상이 위험한가?
------------------------------------------------------------------------
      python tier.py 영상.mp4

  출력 예시:
      영상                     판정        근거
      cera.mp4                위반        프레임간격
            ①빈도    2.0 /  3.0 =  67%   작동기 A
            ①면적   61.8 / 25.0 = 247%   작동기 A
            ...

  3단계의 뜻
      위반      규격(BT.1702) 조건이 성립. 반드시 고쳐야 함
      여백없음  통과는 하지만 한 규칙의 모든 축이 한도의 60% 이상.
                조금만 바뀌어도 뒤집힘
      안전      손댈 필요 없음

  여러 편 한 번에:      python tier.py *.mp4
  빠르게(패턴 생략):    python tier.py --no-pattern 영상.mp4
  경고 기준 조절:       python tier.py --warn 0.5 영상.mp4


2) 규칙별 여백 표 보기 — 어느 축이 얼마나 넘는가
------------------------------------------------------------------------
      python margin.py 영상.mp4

  규칙별 (측정 / 한도 / 여백 %) 와, 적색이 왜 안 걸렸는지 채도 분포까지
  같이 보여 줍니다.


3) 보정하기
------------------------------------------------------------------------
  (a) 규격 위반만 고침 — 기본. 최소 개입
      python psepipe.py 영상.mp4 출력.mp4

  (b) 여백까지 확보 — 모든 축을 한도 아래로
      python psepipe.py 영상.mp4 출력.mp4 --margin 1.0

  (c) 화면전환까지 손대기 — 편집 의도가 크게 바뀝니다. 확인 후 사용
      python psepipe.py 영상.mp4 출력.mp4 --dissolve 5

  (d) 컷 대응 방안만 읽기
      python psepipe.py --cut-playbook

  자주 쓰는 옵션
      --pad 0.5     위반 구간 앞뒤 여유(초). 크게 하면 더 넓게 보정
      --width 320   분석 폭. 여러 편 비교할 땐 반드시 고정
      --json        기계 판독용 출력

  원본이 이미 적합이면 **한 화소도 건드리지 않고** 그대로 복사합니다.


4) 결과 확인
------------------------------------------------------------------------
      python tier.py 출력.mp4          판정이 바뀌었는지
      python margin.py 영상.mp4 출력.mp4   전후 여백 비교

  좌우 비교 영상 만들기 (ffmpeg):
      ffmpeg -i 영상.mp4 -i 출력.mp4 -filter_complex "[0:v]scale=480:-2[a];[1:v]scale=480:-2[b];[a][b]hstack" 비교.mp4


5) 시간이 얼마나 걸리나
------------------------------------------------------------------------
  영상 길이의 5~30배입니다 (17초 영상에 1.5~10분).
  판정(검출기)이 시간의 70% 를 먹습니다. 급하면 --no-pattern 을 쓰세요.


6) 안 될 때
------------------------------------------------------------------------
  ModuleNotFoundError: 파일이 한 폴더에 다 있는지 확인
  ffmpeg 관련 오류: ffmpeg -version 이 되는지 확인
  한글 깨짐(Windows): chcp 65001 을 먼저 실행
