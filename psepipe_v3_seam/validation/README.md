## 불일치 2편 — 사람 눈(프레임 몽타주) 판별 완료

- **Db4Sor9OcyL** (BT 위반 / PC 적합) → **진짜 위반, BT 가 맞다.**
  17.2~17.7s / 25.4~26.1s 에 미용실 리베일 전환 이펙트: 시안→마젠타→노랑→
  **전화면 백색(평균휘도 253/255)**→적→보라 컬러 플래시. 0.5초 안에 휘도가
  100↔253 을 수 회 왕복, 면적 100%. "점멸과 동시에 화면이 바뀌는" 전환
  이펙트인데, ⑤화면전환 조항("빨리 바뀌는 화면도 플래시 기준과 동일하게
  간주")이 정확히 이 경우를 위해 존재한다 — 게다가 여기는 문자 그대로의
  휘도 점멸도 함께 있다(백색 블로우아웃). psecore 는 화면전환 채널 부재 +
  50ms 유효지속 요구로 놓침 = **미탐**.
- **Db4bFuguKZf** (BT 적합 / PC LUM 위반) → **위반 아님, BT 가 맞다.**
  트랙터 주행 POV. 전역 휘도 85~96 으로 평탄, 점멸 없음. 어두운 기둥들이
  화면을 쓸고 지나가며 서로 **다른 화소**가 시차를 두고 어두워질 뿐이다.
  psecore 는 20ms 동기화 그룹의 전환 화소를 합산해 면적 27% 로 과계상 =
  **오탐** (움직임 유발 오탐의 전형). BT 는 화소 동일성 + 국소 평균으로 통과.
  ※ 면적 계상 방식이 판정을 가르는 경계 표본 — 공인 도구 교차검증 때 필수.

## 경계 표본 3 — Db4afDPIFbY (둘 다 적합, 사람 확인 결과 "규격상 적합" 맞음)

애니메이션 임팩트 편집물: 어두운 장면(휘도 12/255) 위에 전화면 백색 임팩트
프레임(휘도 150~201, 면적 95%)이 22초 동안 12회, 2프레임 간격 쌍으로도 등장.
그러나 어느 1초 창에서도 최대 2회 — 모든 표준 계열이 공유하는 "3회/s 초과"
빈도 조건에 미달이라 **적합이 규격 문언대로의 판정**이다 (순수빈도 보조
채널로도 2~3회/s). 검출기 결함이 아니라 규격이 허용하는 회색지대이며,
tier 가 "여백없음 ①(빈도67%/면적273%)" 로 정확히 짚는다. ⑥을 금지문으로
읽으면 2프레임 쌍둥이 플래시가 걸리는, v_burst334 의 실사판 표본 —
공인 도구 교차검증 목록에 포함할 것.
