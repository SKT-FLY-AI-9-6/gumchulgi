## 불일치 2편 — 사람 눈(프레임 몽타주) 판별 완료

- **Db4Sor9OcyL** (BT 위반 / PC 적합) → **진짜 위반, BT 가 맞다.**
  17.2~17.7s / 25.4~26.1s 에 미용실 리베일 전환 이펙트: 시안→마젠타→노랑→
  **전화면 백색(평균휘도 253/255)**→적→보라 컬러 플래시. 0.5초 안에 휘도가
  100↔253 을 수 회 왕복, 면적 100%. "점멸과 동시에 화면이 바뀌는" 전환
  이펙트인데, ⑤화면전환 조항("빨리 바뀌는 화면도 플래시 기준과 동일하게
  간주")이 정확히 이 경우를 위해 존재한다 — 게다가 여기는 문자 그대로의
  휘도 점멸도 함께 있다(백색 블로우아웃). psecore 는 화면전환 채널 부재 +
  50ms 유효지속 요구로 놓침 = **미탐**.
- **Db4bFuguKZf** (BT 적합 / PC LUM 위반) → **위반 아님, BT 가 맞다.**
  트랙터 주행 POV. 전역 휘도 85~96 으로 평탄, 점멸 없음. 어두운 기둥들이
  화면을 쓸고 지나가며 서로 **다른 화소**가 시차를 두고 어두워질 뿐이다.
  psecore 는 20ms 동기화 그룹의 전환 화소를 합산해 면적 27% 로 과계상 =
  **오탐** (움직임 유발 오탐의 전형). BT 는 화소 동일성 + 국소 평균으로 통과.
  ※ 면적 계상 방식이 판정을 가르는 경계 표본 — 공인 도구 교차검증 때 필수.

## 경계 표본 3 — Db4afDPIFbY (둘 다 적합, 사람 확인 결과 "규격상 적합" 맞음)

애니메이션 임팩트 편집물: 어두운 장면(휘도 12/255) 위에 전화면 백색 임팩트
프레임(휘도 150~201, 면적 95%)이 22초 동안 12회, 2프레임 간격 쌍으로도 등장.
그러나 어느 1초 창에서도 최대 2회 — 모든 표준 계열이 공유하는 "3회/s 초과"
빈도 조건에 미달이라 **적합이 규격 문언대로의 판정**이다 (순수빈도 보조
채널로도 2~3회/s). 검출기 결함이 아니라 규격이 허용하는 회색지대이며,
tier 가 "여백없음 ①(빈도67%/면적273%)" 로 정확히 짚는다. ⑥을 금지문으로
읽으면 2프레임 쌍둥이 플래시가 걸리는, v_burst334 의 실사판 표본 —
공인 도구 교차검증 목록에 포함할 것.

## EA IRIS 교차검증 반영 (2026-08-13)

팀이 합성 24편을 EA IRIS(제3자 독립 구현)로 교차검증했다 — 저장소 루트
`IRIS_교차검증_v0.1.md`. 일치 18/24, 불일치 6건 전부 규격 계열 차이로 해명
(자기 채점 약점의 첫 외부 대조). 이어서 문서의 "남은 것 1"을 원문 대조로
해결했다:

- **적색 채도비는 선형광이 맞다.** WCAG 2.2 원문이 같은 문장에서 CIE 1976
  u'v'(선형광 전제)로 전환 거리를 정의하고, IRIS 도 EOTF 복원 LUT
  (첫 값 0.000303527 = (1/255)/12.92) 뒤에서 채도비를 계산한다.
- `saturated_red()` 선형광 패치 적용. A/B: 합성 24편 중 **07(포리곤 유사
  탈채도)·08(등휘도 적녹)만 위반—적색으로 전환** → IRIS 일치 20/24, 실영상
  7편 판정 변화 0 (마스크 면적은 커지나 Δu'v'+면적+빈도 게이트가 걸러냄).
  07 은 "규격의 구멍 — 보조 채널로만 검출"에서 "규격 축 안 검출"로 승격.
- margin.py 의 복제 공식도 동기화.

같은 날 다른 브랜치 업데이트와의 교차 확인:

- **seunghoon 브랜치** (psecore 계열 coherent 모드): 2차 100편 중 16편 사람
  판정 — coherent 정밀도 71%, 미탐 0, **검증된 위반률 5.0%** (95% CI
  2.2~11.2%). 오탐 11편 전원인이 모션("화소값은 빛이 변해도, 내용물이
  옮겨와도 변한다") — 우리 Db4bFuguKZf(트랙터) 판별과 같은 근본 원인을
  독립적으로 재확인. BT 의 화소 동일성+국소 평균이 그 사례를 통과시킨 것과
  정합.
- **jinsuk 브랜치**: 실시간 감시 앱 워크스페이스에 `pse_bt1702.py` 사본이

### 선형광 적색 패치 — 실영상 심층 A/B (판정 너머 채널 내부까지)

표면 판정만이 아니라 적색 채널 내부를 열어 확인했다 (`red_linear_ab.json`,
`red_mask_ab.png`).

- **적색 전환 이벤트: 실영상 7편 전부 0 → 0** (순수 계수로도 0). 변경 전에도
  후에도 적색 축은 실영상에서 이벤트 자체가 없어, 판정에 대한 영향은 정확히 0.
- 커진 것은 "순간 채도적색 면적" 통계뿐 (Db4Sor9OcyL 최대 1.6→19.6%,
  Db4afDPIFbY 0.5→6.1%). 최대 면적 프레임을 눈으로 확인한 결과, 선형광
  정의가 새로 포함하는 화소는 **주황 계열 색보정·적갈색 머리카락·화염
  그래픽** 등이다 — 감마 복원이 G 채널을 눌러 주황이 채도비 0.8 을 넘는다.
  cera 의 진적색 조명은 감마 정의도 이미 66% 를 잡고 있었다 (+2%p 차이).
- 남는 위험 표면은 하나: **주황↔한색 계열이 3회/s 초과로 교대하는 편집물**은
  이제 적색 축에 걸릴 수 있다 (감마 정의에서는 안 걸렸다). 이는 IRIS 도
  동일하게 잡는 방향이라 교차검증 심판과 일치하며, Δu'v'·면적 25%·빈도
  게이트는 그대로다. 편집자 UI 가 "적색 면적"을 노출한다면 따뜻한 필터
  영상에서 수치가 커 보일 수 있음은 알아둘 것.
