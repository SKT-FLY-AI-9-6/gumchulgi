팀이 합성 24편을 EA IRIS(제3자 독립 구현)로 교차검증했다 — 저장소 루트

(자기 채점 약점의 첫 외부 대조). 이어서 문서의 "남은 것 1"을 원문 대조로
해결했다:

- **적색 채도비는 선형광이 맞다.** WCAG 2.2 원문이 같은 문장에서 CIE 1976
  u'v'(선형광 전제)로 전환 거리를 정의하고, IRIS 도 EOTF 복원 LUT
  (첫 값 0.000303527 = (1/255)/12.92) 뒤에서 채도비를 계산한다.
- `saturated_red()` 선형광 패치 적용. A/B: 합성 24편 중 **07(포리곤 유사
  탈채도)·08(등휘도 적녹)만 위반—적색으로 전환** → IRIS 일치 20/24, 실영상
  7편 판정 변화 0 (마스크 면적은 커지나 Δu'v'+면적+빈도 게이트가 걸러냄).
  07 은 "규격의 구멍 — 보조 채널로만 검출"에서 "규격 축 안 검출"로 승격.
- margin.py 의 복제 공식도 동기화.

같은 날 다른 브랜치 업데이트와의 교차 확인:

### 선형광 적색 패치 — 실영상 심층 A/B (판정 너머 채널 내부까지)

표면 판정만이 아니라 적색 채널 내부를 열어 확인했다 (`red_linear_ab.json`,
`red_mask_ab.png`).

- **적색 전환 이벤트: 실영상 7편 전부 0 → 0** (순수 계수로도 0). 변경 전에도
  후에도 적색 축은 실영상에서 이벤트 자체가 없어, 판정에 대한 영향은 정확히 0.
- 커진 것은 "순간 채도적색 면적" 통계뿐 (Db4Sor9OcyL 최대 1.6→19.6%,
  Db4afDPIFbY 0.5→6.1%). 최대 면적 프레임을 눈으로 확인한 결과, 선형광
  정의가 새로 포함하는 화소는 **주황 계열 색보정·적갈색 머리카락·화염
  그래픽** 등이다 — 감마 복원이 G 채널을 눌러 주황이 채도비 0.8 을 넘는다.
  cera 의 진적색 조명은 감마 정의도 이미 66% 를 잡고 있었다 (+2%p 차이).
- 남는 위험 표면은 하나: **주황↔한색 계열이 3회/s 초과로 교대하는 편집물**은
  이제 적색 축에 걸릴 수 있다 (감마 정의에서는 안 걸렸다). 이는 IRIS 도
  동일하게 잡는 방향이라 교차검증 심판과 일치하며, Δu'v'·면적 25%·빈도
  게이트는 그대로다. 편집자 UI 가 "적색 면적"을 노출한다면 따뜻한 필터
  영상에서 수치가 커 보일 수 있음은 알아둘 것.

### 이 코퍼스의 성격을 먼저 — 전 편이 "문턱 ±1cd" 경계 설계다

pass 116편은 한도 직전까지 가고, fail 22편은 한도를 **0.1~2cd/m² 만** 넘는다
(예: 회색 158↔178 = Δ20.7cd, 한도 20). 실사 위반(Δ100cd+, 면적 95%)과 다른
차원의 시험 — 문언 대비 **실효 문턱의 보정 상태**를 재는 자다. 실사 19편
미탐 0 과 모순되지 않는다.

## 경계 보정 3층 적용 (2026-08-14) — trace 84.1% → 91.3%

trace 가 규명한 3층 원인을 정본에 적용하고 3면 자로 회귀를 마쳤다.

1. **EOTF 조각별 sRGB** — `decode_linear()` 를 IEC 61966-2-1 조각별
   공식(8bit 는 LUT)으로. 치료기(blazebvd)·IRIS 와 동일 정의가 됐다.
2. **계수 재설계** — 플래시 계수를 "같은 방향 연속 전환은 합성 변화
   하나로 병합, 1초 창 계수 = 변화 수/2"로 (3.5 같은 반값 등장, trace
   교대 세트가 검증한 규격 문언 독법). 화소 동일성은 선형 사슬에서
   **병렬 묶음**(cluster)으로 — 두 영역 엇박 점멸이 독립 시퀀스가 된다
   (inf01 회복). 같은 프레임에 양방향이 얽히지 않고 넘으면 각각 등록,
   얽히면 모션으로 폐기(순방향 상쇄의 일반화).
3. **블러 → 프레임 일관성 동의** — 휘도 자체를 블러하던 것을, 델타·면적은
   비블러 정밀값으로 재고 "유해 면적의 과반이 국소 평균 델타와 부호·크기
   (문턱의 50%)로 동의"해야 인정하는 프레임 게이트로 교체. 팬/셰이크
   방어는 유지되고 경계 델타 침식이 사라진다. 면적 관문에 리사이즈 보상
   AREA_EPS=0.002 (0.005 는 24.6~24.7% 설계 pass 를 오탐 — 실측으로 확정).

**회귀 (3면 자):**
- 합성 24: 설계 정답 24/24 전부 일치 (변화 없음, 모션 대조군 25~27 적합 유지)
- 실사 7: 판정 전원 불변 (위반 4·적합 3). 유일한 축 변화 — Db4Sor9OcyL 의
  플래시 축이 6회/s→3회/s 로 내려가 화면전환 축 단독 위반이 됐다. 구 계수가
  2프레임 감쇠 램프를 전환 2회로 부풀리던 것의 정정이며(합성 변화 병합),
  같은 독법을 trace 교대 세트가 정답으로 검증한다. 판정은 위반 그대로.
- trace 138: **일치 126 (91.3%)** = 특이도 114/116 (98.3%) + 민감도 12/22
  (55%, 종전 5%). 적색 48/48 유지.

- 미탐 10: (a) 다조각 고둘레 패턴의 리사이즈 침식 — **원해상도(width=1920)로

  (b) 블러 창보다 얇은 기하 + 여유 0.1cd (f004f013) — 구 검출기도 동일하게
  못 보던 부류, 부호 단독 완화는 모션 오탐 재유입 위험이라 보류.

  방향**으로 점멸하면 변화 마스크가 합집합이 돼 묶음이 다리를 놓는다
  (합산 금지 취지 위반). 별도 과제로 기록.

blazebvd 브랜치에 학습 산출물이 올라왔다: AWS GPU, DAVIS+확장 합성 플리커
